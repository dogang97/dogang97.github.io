About

모델을 만드는 대신,
모델이 믿을 수 있는 데이터를 만듭니다.

언어인지과학과 Language & AI를 전공하며 언어 데이터를 다루는 법을 배웠고, DICORA NLP LAB에서 감성분석 학습 데이터셋을 만들며 실무를 시작했습니다.

이후 와이즈넛에서 법률·정부 포털 챗봇의 검색 사전을, NCsoft에서 Varco LLM 학습 데이터 구축 PM을, SK텔레콤에서 AICC RAG 평가와 통화 데이터 개인정보 마스킹을 맡았습니다.

제가 잘하는 일은 기준을 만드는 일입니다. 무엇이 좋은 답인지, 어떤 문서가 정답 근거인지, 어디까지가 개인정보인지 — 상담원·개발자·기획자가 같은 기준으로 판단할 수 있게 문서와 도구를 만듭니다.

2026년 7월부터 쿠팡 Data Management에서 일하고 있습니다.
